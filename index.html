About Me

I'm a Computer Science and Engineering student with a profound passion for Data Engineering. My journey in technology began with competitive programming, where I developed strong problem-solving skills and a deep understanding of algorithms and data structures. These foundational skills have become the backbone of my pursuit in Data Engineering.

My professional journey has evolved through three major phases: mastering competitive programming to build strong fundamentals, exploring Generative AI and Machine Learning to understand intelligent systems, and finally specializing in Data Engineering where I can design and optimize data pipelines at scale. This progression reflects my commitment to understanding how data flows, transforms, and creates value in modern applications.

My technical expertise spans across modern data engineering tools and platforms. I'm proficient in ETL development using Apache Airflow and DBT, work extensively with cloud platforms like AWS and Azure, and have hands-on experience with big data technologies including Apache Kafka, Apache Spark, and Snowflake. I'm particularly interested in designing scalable data architectures, implementing real-time streaming solutions, and optimizing data warehouse operations for performance and cost-efficiency.

Currently, I'm actively seeking internship opportunities and collaborative projects where I can apply my technical skills to solve real-world data challenges. If you have an interesting problem to solve, a project to collaborate on, or simply want to discuss data engineering best practices, I'd love to connect. Let's build something impactful together!
